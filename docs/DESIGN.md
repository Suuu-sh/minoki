# Okiyo（おきよ）— 連帯早起きアプリ 設計書

作成: 2026-10-18 / 担当: 設計・UI = Claude、それ以外 = Codex(GPT)

## コンセプト
**「誰か1人でも寝坊したら、全員のストリークが0に戻る。」**
2〜6人のグループで朝の起床を報告し合う。自分のためではなく「仲間のために起きる」という社会的な圧力で早起きを続けさせる。

## キャラクター: ピヨ（Piyo）
- 黄色いひよこのぬいぐるみ風キャラクター。青いナイトキャップをかぶる。画面の役割に合わせた透明PNGを `app/assets/images/piyo/` に置き、`Piyo` の必須 `pose` で選ぶ。ウェルカムでは既存の `wake-time` / `home` ポーズを大きく表示する。
- mood による動きは4つ: `sleepy`（ねむい）、`happy`（ご機嫌）、`cheer`（全員起きた）、`sad`（ストリークが途切れた）
- 画面ごとのポーズ: 起床時刻=`wake-time`、仲間参加=`join`、今日=`home`、通知案内=`notify`、メンバー招待=`members`、チェックイン前/後=`checkin-sleep`/`checkin-awake`、達成=`celebrate`、途切れ=`broken`。ポーズ画像と mood は別概念。mood は引き続きアニメーション状態に使う。
- 口調: やわらかい関西寄りではなく、素直な子ども口調。「おきて〜」「みんなえらい！」
- ストリークが長いほど成長する（卵→ひよこ→帽子→王冠）。v1では見た目のバッジのみ。

## デザインルール（2026-10 Clucky参照リデザイン）
| 項目 | ルール |
|---|---|
| 背景・カード | クールグレー `#EAEAEA` の面に、白いボーダーレスカードを重ねる |
| アクセント | 焦げオレンジ `#C73701` を主CTAに限定。状態は文字・淡い面と併用 |
| 角丸 | カード22、CTA14、補助ピルは小さく統一。カードに枠線・下影を足さない |
| ボタン | 高さ56のフラットCTA。左に行為、右に矢印。副操作はグレー面かテキスト |
| 文字 | システムフォント。見出しは強い黒の太字、時刻は大きなtabular-nums |
| アイコン | SF Symbols（expo-symbols）を使い、絵文字は使わない |
| ダークモード | 同じ階層とアクセント関係を維持し、暗いグレー面へ置換（`app/src/theme.ts`） |

**マスコット背景:** ピヨの透過PNGは配置先の面にそのまま載せる。別色の円・マット・人工背景は、明示的に依頼された場合を除き敷かない。

**アニメーション:** ピヨはすべて静止表示が基本。チェックイン成功時だけ、ねむり姿から起きた姿へ短いクロスフェードで切り替え、Reduce Motion が有効なら即時切り替えにする。

### 確認範囲
- Codex iOS Simulator（親エージェント確認）: welcome→グループ作成→Home、長押しcheck-in→Home、Membersの共有シートを開閉。ライトのwelcome、ダークのMembers共有シート・celebrate・brokenも確認。
- 物理端末、リリースビルドでの性能計測、フルモーション録画は未確認。SimulatorのMetro警告で確認した DateTimePicker の `onChange` 非推奨は `onValueChange` へ移行済み。別に表示された `onAnimatedValueUpdate` listener 警告は発生元未調査のため残存扱い（LogBoxで隠さない）。

## 画面とナビゲーション
```
(onboarding)  ← 完了後は replace（戻れない）
  welcome      ピヨの紹介と「はじめる」
  wake-time    起床時刻の選択（ネイティブのDatePicker）
  group        グループを作る／招待コードで参加する
(tabs)
  today        ホーム: 今週の記録、次の起床時刻、全員の状態と起床CTA
  members      メンバー一覧、連続記録と招待コード
checkin        fullScreenModal: 「長押しでピヨを起こす」→ 起床記録
celebrate      fullScreenModal: 全員起床したときの演出と曜日ドット
broken         fullScreenModal: 誰かが寝坊したときにストリークが0になる演出
```

## ルール（v1）
- 起床ウィンドウ: 設定した時刻の前後30分以内にチェックインすると「起床」
- ウィンドウが終わった時点で全員が起床していればストリーク+1。1人でも欠ければ0にリセットする
- 判定はサーバー側（Cloudflare Workers + D1、Cron Trigger で5分ごと）で行う（Codex担当）。v1のクライアントはローカルのモック（zustand）で動かす
